ClipAgent 7.8.19

  • Prevents the desktop app from connecting to an older ClipAgent backend left on the configured port.
  • Verifies that the frontend and backend versions match before opening the app, and automatically selects a free local port when necessary.
  • Keeps YouTube's failing Android VR player client disabled while bundling the current stable yt-dlp, EJS, and Deno runtime.
  • Reports jobs containing only an incomplete .part file as failed; Partial download now requires a media file that ffprobe can open.
  • Adds the ClipAgent and yt-dlp versions to job logs for faster support diagnosis.
