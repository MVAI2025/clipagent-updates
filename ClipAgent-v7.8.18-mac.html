ClipAgent 7.8.18

  • Updated yt-dlp and excluded YouTube's retired Android VR player client to prevent Preview clips from failing with HTTP 403.
  • Preview and CSV jobs now report Failed or Partial download when playable clips were not created, instead of treating an error manifest as a completed video.
  • Find download is only offered when a playable media file exists, with clearer error guidance available directly in Job Tracking.
  • Public YouTube downloads no longer attach members-only browser cookies unless the user explicitly enables members-only access.
